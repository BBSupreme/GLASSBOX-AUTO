# Source Material

This directory is for raw or near-raw evidence used by GLASSBOX-AUTO.

## Rules

- Preserve the original filename where practical.
- Record source/provenance and relevant publication/validity dates.
- Do not modify a source file to make it fit the model.
- Normalize into separate structured data.
- Treat historical offers as historical evidence, not current offers.
- Third-party material remains subject to its original rights and terms; see the repository `NOTICE`.

## Current files

### `2025 leasing matrix.xlsx`
Historical personalized baseline used as inspiration for the 2026 rebuild. It is not the canonical 2026 engine.

### Hyundai IONIQ 5 private-leasing price list
The project also contains an original Hyundai IONIQ 5 PDF source dated/updated 2024-12-18 with stated validity through 2025-06-30. Its binary import is still pending; see `docs/MIGRATION_MANIFEST.md`.
